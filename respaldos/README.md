# Respaldos

Guardar cada versión de trabajo en la rama principal, en respaldos/AAAA-MM-DD/vNNN/, usando el día de trabajo en Chile. Si una jornada tiene varias versiones, crear una carpeta para cada una dentro de la misma fecha.

Conservar los nombres y el contenido de los originales. Guardar el código, las pruebas, las evidencias y el ZIP original dentro de la versión. Conservar cada variante en su propia subcarpeta. Mantener fuera del repositorio los secretos, los datos personales y los informes reales.

Actualizar el [índice de versiones](INDICE_VERSIONES.md) al añadir un respaldo. GitHub Pages excluye este directorio del sitio oficial.
